
# 🌸 Femlexa — Smart Women's Period Tracker

Femlexa is a smart women-focused healthcare application designed for period tracking, wellness monitoring, reminders, and health management.

---

## 📌 Overview

This project focuses on creating an accessible and user-friendly healthcare platform for women to monitor menstrual cycles, wellness, and daily health insights.

---

## 🚀 Features

- Period cycle tracking
- Smart health reminders
- Wellness monitoring
- User-friendly interface
- Personalized healthcare support

---

## 🛠️ Technologies Used

- Python
- HTML
- CSS
- JavaScript

---

## 🎯 Objective

To develop a smart and accessible women’s healthcare platform focused on improving health awareness, tracking, and wellness management.
