
# 🌸 Femnexa — Smart Women's Period Tracker

Femnexa is a smart women-focused healthcare application designed for period tracking, wellness monitoring, reminders, and personalized healthcare support.

---

## 📌 Overview

Femnexa focuses on creating an accessible and user-friendly platform for women to monitor menstrual cycles, daily wellness, and health insights efficiently.

The application aims to support women through smart tracking features, reminders, and wellness-focused healthcare management.

---

## 🚀 Features

- 📅 Period cycle tracking
- ⏰ Smart reminders & notifications
- 💖 Wellness monitoring
- 📊 Health insights
- 🩺 Women-focused healthcare support
- 🎨 User-friendly interface
- 🔒 Secure and private experience

---

## 🛠️ Technologies Used

- Python
- HTML
- CSS
- JavaScript

---

## 🎯 Objective

To develop a smart and accessible women’s healthcare platform focused on improving health awareness, cycle tracking, and wellness management through technology.
